10 Board UI Designs

Different tile structures, layouts, info hierarchies

#1Strip Tiles
Classic approach. Color strip on inner edge. Name centered, price below. Clean and proven.
color stripstacked name+pricecream bggreen felt frame
#2Floating Cards
Each tile is a separate rounded card with a gap between them. Feels like individual property cards laid on a table.
separated tilesrounded cornersdark bggold accent
#3Full-Color Blocks
No color strip — the ENTIRE tile is the group color. Bold, vibrant, instant visual grouping. Name in white over color.
full tile colorwhite text on colorno stripsbold & vibrant
#4Dot Indicators
No color strips. Group color shown as a glowing dot at the top of each tile. Minimal, modern, GitHub-dark inspired.
color dotsno stripspill-shaped tilesdark minimal
#5Icon-First
Each tile shows a city EMOJI as the primary element. Name is secondary and tiny. The board becomes a visual map of icons.
emoji iconsname secondarythin color barlight & warm
#6Wide Color + Vertical Name
Color strip is wide (12px) with the name INSIDE it, written vertically. Price in the remaining tile area. Dense info.
wide color stripvertical namename inside coloreditorial
#7Gradient Fill
Like #3 but softer — group color as a translucent gradient fill. Tiles blend and glow. Moody, atmospheric.
gradient bgsemi-transparentglowingatmospheric dark
#8Colored Border Only
No color fill at all. Group identity shown purely as a colored BORDER on the inner edge. Ultra-minimal, architectural blueprint feel.
border-only colorno fillwhite tilesarchitectural
#9Price-First
PRICE is the biggest element on each tile (top, bold, cyan). City name is tiny below. Trader's board — money talks first.
price dominantname secondarythin color bartrader aesthetic
#10Vintage Ticket
Tiles look like vintage train tickets or stamps. Perforated dot texture, aged paper color, warm wood board. Old India railways feel.
ticket/stamp styledot texturevintage paperwood board
